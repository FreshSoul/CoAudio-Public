# CoAudio 超详细新手引导

这份引导面向第一次使用 CoAudio 的用户。你可以把它当成从下载安装到完成第一条声音检索、试听、整理、创作、导出和云端协作的完整路线图。

## 0. 先理解 CoAudio 的几个概念

### 本地库

本地库管理你电脑或 NAS 上已有的音频文件。CoAudio 扫描文件夹后只建立索引，不会移动源文件。

适合：

- 个人音效库
- 离线工作
- NAS 或移动硬盘素材
- 快速试听和拖进 DAW

### 音频包

CoAudio 会根据文件所在目录生成音频包视图。比如：

```text
D:\SoundLibrary\Whooshes\Long\
D:\SoundLibrary\Impacts\Metal\
```

这些目录会在侧栏中变成可浏览、可筛选、可分组的包。

### 语义检索

传统搜索依赖文件名和文字字段；语义检索会给音频和文字生成向量。启用后，你可以用自然语言找声音，例如“冰冷的科幻空气释放声”。

语义检索需要先生成 CLAP 嵌入。没生成前，普通搜索仍然可用。

### 元数据

元数据是声音的说明书，包括文件名、描述、关键词、UCS 分类、设计师、项目、厂牌、时长、采样率、声道、BWF/iXML 信息等。

素材越多，元数据越重要。

### 云端库

云端库用于团队共享或跨设备使用。云端分为组织库和个人库：

- 组织库：B 端/团队使用，通常上传源文件到云端。
- 个人库：面向个人分布式使用，可以同步元数据和本机持有关系。

### 合成台

合成台是一个轻量多轨声音设计工作区。你可以输入一句创作描述，让 AI 拆成多个声音层，从素材库里找候选，加入时间线后混合导出。

### 拟音台

拟音台是一块可以「演奏」的舞台。载入一张画面（或用预置场景），CoAudio 会判断画面里每一块是什么材质；你用鼠标在上面走、敲、擦，就会实时发出对应的脚步、碰撞和摩擦声。声音可以来自素材库里的真实录音，也可以全部由程序合成。录下一段演奏后，可以直接导出成 WAV 并入库。也可以载入一段视频，对着画面演，把每一下放到时间线上逐个修改，最后导出和视频对齐的音轨或带声视频。

## 1. 安装和启动

### 普通用户

如果你拿到的是安装包或便携版：

1. 打开 `CoAudio-Setup-版本号.exe` 或 `CoAudio-Portable-版本号.exe`。
2. 安装或直接运行。
3. 启动后，CoAudio 会打开桌面窗口，并自动启动本地音频服务。

如果启动失败，通常检查三件事：

- Windows 安全软件是否拦截了应用
- 本地端口是否被旧进程占用
- 应用目录中是否带有 sidecar 资源

### 关闭和退出

点窗口右上角的 × 只是把窗口收进系统托盘，CoAudio 仍在后台运行，这样再次唤出时是瞬间的，正在播放的内容和选中状态也都保留。

- 唤出 / 收起窗口：按全局快捷键 `Ctrl+Alt+S`（可在「设置 → 快捷键」里改），或右键托盘图标选「显示 / 隐藏 CoAudio」。
- 真正退出：右键托盘图标，选「退出 CoAudio」。

### 更新

安装版会在启动后自动检查更新，发现新版本就在后台下载，下载完成后在下次退出时自动安装。你也可以手动操作：

1. 打开「设置 → 关于」。
2. 点「检查更新」。
3. 下载完成后点「重启并更新」。

便携版不能原地更新，检查到新版本后点「打开下载页」，下载新的便携版替换即可。

几个需要知道的情况：

- 更新包从 GitHub 下载。网络连不上 GitHub 时会提示检查失败（例如 `ERR_HTTP2_PROTOCOL_ERROR`），这时可以找管理员要安装包，直接覆盖安装旧版本，数据不会丢。
- 装过 GPU 加速包的用户，升级后会先回到 CPU 模式，需要在「设置 → 音频库 → AI 语义检索」里重新点一次「启用 GPU 加速」。

### 开发环境用户

项目依赖：

- Node.js 22.12+
- Python 3.11+
- 可选：ffmpeg、ffprobe、bwfmetaedit
- 可选：torch、transformers、hnswlib 等 AI/CLAP 依赖

第一次安装：

```bash
npm run setup

cd api
python -m venv .venv
.venv/Scripts/activate
python -m pip install --upgrade "pip>=26.2" "setuptools>=83"
pip install -r requirements.txt

cd ..
npm run dev
```

启动后会出现 Electron 窗口。前端通常运行在 Vite 开发服务上，本地 sidecar 默认由 Electron 拉起。

## 2. 第一次打开后做什么

第一次打开 CoAudio 时，建议按这个顺序：

1. 添加本地音频文件夹。
2. 等待扫描完成。
3. 先用普通搜索确认素材能搜到。
4. 生成语义索引。
5. 用自然语言搜索。
6. 试听、收藏、编辑元数据。
7. 根据需要配置 AI 和云端。

## 3. 添加本地音效库

1. 在左侧侧栏找到本地库区域。
2. 点击添加文件夹。
3. 选择你的音效库根目录，例如：

```text
D:\SoundLibrary
E:\Projects\GameAudio\SFX
\\NAS\Audio\SFX
```

4. CoAudio 会开始扫描。
5. 扫描完成后，素材会出现在主列表中。

### 扫描时会发生什么

CoAudio 会读取：

- 文件路径
- 文件名
- 扩展名
- 时长
- 采样率
- 声道数
- 格式
- 位深
- 文件大小
- 修改时间
- BWF/iXML/RIFF INFO 等嵌入元数据
- UCS 命名中可解析出的分类信息

它不会移动你的源文件。

### 如果扫描后没有素材

检查：

- 文件夹里是否真的有音频文件
- 文件格式是否被支持
- 外部硬盘或 NAS 是否在线
- 路径权限是否正常
- 设置页里的扫描状态是否报错

## 4. 浏览和筛选素材

主界面通常由几部分组成：

- 顶部：搜索框、AI/语义开关、合成台和拟音台入口、主题和账户入口
- 左侧：全部资源、收藏夹、最近使用、音频包、分组、云端库
- 中间：结果表格或资源网格
- 右侧：检视器和元数据面板

### 全部资源

显示当前本地库或当前云端库里的所有素材。

### 收藏夹

显示你标记为收藏的素材。适合保存常用爆点、UI、脚步、whoosh、转场等。

### 最近使用

显示最近试听或使用过的素材，方便回到刚刚听过的声音。

### 音频包

按目录组织素材。你可以点击某个包，只看该包下的素材。

### 虚拟分组

你可以给音频包建立分组，例如：

- 常用库
- 项目 A
- 武器
- 环境
- 人群
- UI

虚拟分组不会移动磁盘上的真实文件，只改变 CoAudio 里的组织方式。

## 5. 普通搜索

在搜索框输入关键词，例如：

```text
metal hit
footstep
rain
magic
爆炸
机械
门
```

普通搜索会匹配文件名、描述、关键词、UCS 分类、项目、设计师等字段。

适合：

- 已经知道素材命名规则
- 搜索明确词汇
- 找某个包或某个项目里的文件
- 快速筛掉不相关内容

## 6. 语义检索

语义检索适合“不知道文件怎么命名，但知道想听什么”的场景。

### 先生成语义索引

1. 打开设置页。
2. 找到语义检索/CLAP 相关区域。
3. 点击生成或继续生成嵌入。
4. 等待任务完成。

如果素材很多，第一次生成会比较久。之后新增素材只需要增量处理。

### 语义搜索示例

你可以输入：

```text
潮湿地下室里的远处水滴声
厚重的金属撞击，带很短的尾音
未来科技门打开，干净、低频、机械
巨兽脚步落在泥地上
魔法能量聚集然后爆开
```

打开 AI/语义开关后，搜索结果会按语义相似度返回。

### 查找相似声音

当你听到一条接近目标的声音时，可以使用“查找相似”。CoAudio 会用这条声音的音频向量去找相似素材。

适合：

- 找同一套 Foley 的其他变体
- 找同风格 whoosh
- 找同类 UI 点击
- 找同质感爆炸层
- 给合成台扩展候选素材

## 7. 试听素材

选择一条素材后，右侧检视器会显示波形和播放控制。

常用操作：

- 点击播放/暂停
- 拖动波形定位
- 选择片段区域试听
- 用键盘上下切换素材
- 使用 Shift + 滚轮快速浏览
- 查看多声道波形

### 实时效果

检视器内置：

- EQ
- Pitch
- Volume
- Reverb
- Delay

这些效果用于快速判断素材是否适合，不会自动改写源文件。

例如，你可以：

- 把 whoosh 降几个半音听是否更厚
- 给短撞击加一点混响判断空间感
- 用 EQ 削掉低频判断是否适合 UI
- 快速提高音量听细节

## 8. 拖进 DAW/WWISE

### 本地素材

直接从列表或检视器拖拽到 DAW。CoAudio 会把真实本地文件路径交给 DAW。

### 云端素材

云端素材没有本机固定路径。拖拽时流程是：

1. CoAudio 请求云端下载接口。
2. 云端验证权限。
3. 当前电脑下载素材到临时目录。
4. Electron 把临时文件路径交给 DAW。

如果你没有下载权限，拖拽会失败。

## 9. 编辑元数据

选中素材后，在右侧元数据面板中可以查看和编辑信息。

常见字段包括：

- 描述
- 关键词
- 备注
- 设计师
- 项目/节目
- Library
- UCS Category
- UCS Subcategory
- CatID
- 收藏状态

### 单条编辑

1. 选中素材。
2. 打开右侧元数据面板。
3. 点击编辑。
4. 修改字段。
5. 保存。

### 批量编辑

1. 在结果列表中多选素材。
2. 打开元数据批量编辑。
3. 输入要统一写入的字段。
4. 确认保存。

批量编辑适合：

- 给一批素材加项目名
- 给一个包补关键词
- 统一设计师字段
- 批量设置 UCS 分类

### 云端编辑历史

云端库支持字段级历史。多人协作时，可以查看谁在什么时候把哪个字段从什么值改成了什么值。

## 10. 收藏和最近使用

### 收藏

当你发现常用素材时，可以点击收藏。收藏不会改变文件，只在 CoAudio 里记录。

适合收藏：

- 常用 whoosh
- 常用 UI
- 高频脚步
- 项目基准素材
- 好用的冲击层

### 最近使用

CoAudio 会记录最近使用过的素材，方便你回到刚刚听过或拖过的声音。

## 11. 音频包和虚拟分组

### 音频包

音频包通常来自目录。比如一个文件夹就是一个包。

你可以：

- 点击包筛选素材
- 多选包筛选
- 查看包内数量
- 删除包对应文件
- 将包加入虚拟分组

### 虚拟分组

虚拟分组是 CoAudio 里的整理结构，不改变真实目录。

推荐分组方式：

- 按项目：Project A、Project B
- 按用途：UI、Foley、Ambience、Weapons
- 按常用程度：Favorites、Daily、Archive
- 按质量：精选、待整理、低优先级

## 12. 保存搜索

如果某个搜索经常用，可以保存下来。

例如：

- “雨 夜 城市”
- “metal impact”
- “UI click bright”
- “magic whoosh”
- “需要补元数据”

保存搜索能让你快速回到某个工作上下文。

## 13. 导出和转码

CoAudio 支持批量导出素材。

常见用途：

- 把选中的素材复制到项目目录
- 转成统一格式
- 统一采样率
- 输出给剪辑、动效、外包或引擎团队

可能的导出设置包括：

- 目标目录
- 格式
- 采样率
- 声道数
- 位深

MP3、FLAC、AAC 等格式通常需要 ffmpeg。

## 14. AI 设置

CoAudio 的大模型能力是可选的。即使不配置大模型，也可以使用本地扫描、普通搜索、语义检索、试听、元数据编辑和导出。

配置大模型后，可以使用：

- 自然语言搜索解析
- 批量 AI 打标
- 合成台自动拆层
- 拟音台 AI 识图（需要能看图的模型）

### 配置步骤

1. 打开「设置 → 大模型」。
2. 选择协议：「Anthropic（Claude）」或「OpenAI 兼容」。国内各家大模型服务、自建网关一般选 OpenAI 兼容。
3. 需要时填 Base URL（用官方接口可以留空）。
4. 填入 API Key。
5. 填「检索/精修模型」和「批量打标模型」。打标量大，可以用便宜一些的模型。
6. 点保存。CoAudio 会先用这组配置发一个极小的请求，验证通过才保存。

API Key 只保存在本机配置中，不会上传到云端。

## 15. AI 批量打标

AI 批量打标可以帮助你为素材生成：

- 描述
- 关键词
- UCS 分类建议

推荐工作流：

1. 先扫描和探测本地库。
2. 生成语义索引。
3. 选中一批需要整理的素材，或选择只处理未打标素材。
4. 启动 AI 批量打标。
5. 抽查结果。
6. 必要时手动修正。

不要把 AI 结果当成永远正确的标准。它适合做第一轮整理和建议，人仍然应该抽查关键资产。

## 16. 合成台入门

合成台是 CoAudio 的轻量声音设计工作区。

### 打开合成台

点顶栏的「合成台」。右上角「关闭」只是收起，正在做的内容会自动保留，下次打开接着做。

### 用一句话开始

在顶部「声音描述」框里输入 brief，例如：

```text
黑暗魔法箭命中石墙，带碎石和低频冲击
未来飞船舱门打开，液压、空气释放、电子提示音
巨型机器人脚步落在湿润混凝土上
```

点「拆层」。如果已配置大模型，CoAudio 会把 brief 拆成一个「基底」和几个叠加层，每层自动检索候选素材。

没有配置大模型也能用：在左栏「检索层」旁点「手动加一层」，自己写检索词。

### 挑选候选

左栏每一层是一张卡片：

- 检索词可以直接改，按回车重新检索。
- 点候选试听，再点一次停止；听过的会有标记。
- 点候选右侧的 ＋，把它加到时间轴（每次新建一条叠加轨）。
- 候选也可以直接拖到 DAW 或桌面。
- 列表底部「加载更多」看更多候选。

浏览云端库时，层标题旁会显示「云库」，表示在当前云端库里检索。

### 播放和电平

顶部传输条从左到右：

- 播放 / 暂停（空格），停止并回到开头。
- 当前时间和总时长。
- 电平表：显示主输出音量，绿色正常、琥珀色偏响、红色表示过载。常亮红色时，调低主音量或某几轨的音量。
- 缩放：放大 / 缩小时间轴（也可以 Shift+滚轮；Alt+滚轮调轨道高度）。
- 主音量。

试听云端素材时，声音直接从网络播放，不经过合成台的混音，所以电平表不会动。

### 编辑时间线

时间轴第一行「合成预览」显示所有层叠加后的波形，默认静音，只用来看整体形状。

每条轨道左侧可以静音、独奏、调音量。片段上可以：

- 拖动片段移动位置
- 拖左右边缘裁剪
- 拖上方两角做淡入、淡出
- 拖片段中间的横线调音量
- 右键：循环填充、音高 +1 / −1 半音、音高复位、删除片段

### 保存和导出

- 「保存」：第一次保存为一个合成项目，之后每次保存都覆盖这个项目。
- 「导出」：按当前导出设置渲染整段，写进音频库并重新入库，马上就能搜到。
- 「导出」旁的箭头打开导出设置：格式（WAV / FLAC / MP3）、声道、采样率、位深、导出目录。导出目录默认是音频库里的 `CoAudio Renders`，必须在已索引的音频库文件夹之内。

MP3 和 FLAC 需要 ffmpeg，缺少时会提示。如果有片段的素材没加载成功，导出会被取消，并列出是哪几条。

建议先用 WAV 24bit/48k 输出，再按项目需要转码。

## 17. 拟音台入门

拟音台适合快速做脚步、碰撞、摩擦这类跟着画面走的声音：先让 CoAudio 知道画面里每一块是什么材质，再用鼠标「演奏」，最后录下来导出。

### 打开拟音台

点顶栏的「拟音台」，按 Esc 或右上角「关闭」退出。界面分三栏：

- 左栏「场景与声音」：选场景、识别画面、选空间和音源。
- 中间是舞台：画面和识别出的区域。
- 右栏「素材池」：每块区域实际用到的录音（只在用素材库发声时显示）。

### 准备场景

在左栏「场景」里二选一：

- 选一个预置场景：海岸、棉布、林间小径、室内、雪原，或「空白」（整块舞台只有一种材质）。
- 点「载入图片」用你自己的画面，比如游戏截图、分镜、概念图。

载入图片后，CoAudio 会推断画面各处的材质。识别方式有两种：

- **颜色识别**：按颜色和纹理推断写实材质，在本机进行，速度很快，但可能认错，比如把蓝色的墙当成水。
- **AI 识图**：把图片发给你配置的大模型，能认出科幻、魔法、卡通这类非写实内容。需要先配置大模型，并且模型能看图。识别期间再点一次可以取消。

「空间」决定声音的环境感：拟音棚、室内、林间、户外开阔、雪地，或「无（干声）」。

### 演奏

顶栏选择动作，然后在舞台上操作：

| 动作 | 操作 | 效果 |
|---|---|---|
| 脚步 | 按住拖动 | 每走一段距离落一步，走得越快越重，足够快就变成跑步。脚下是什么材质就踩出什么声音。 |
| 碰撞 | 点击 | 点一下就是一次撞击，之前移动越快越重；拖动中急停也会撞一下。 |
| 接触 | 按住拖动 | 持续摩擦或划水，速度控制音量和亮度，停手就静音；跨过区域交界会自动换声。 |

左栏「声音」里还可以调：

- **音源**：「素材库」用库里的真实录音（库里找不到合适素材的组合会自动改用合成）；「纯合成」全部程序合成，不需要素材库，每一下都不一样。
- **变化度**：0 表示每一下都一样，100 表示自然变化。
- **步长**：每走多远落一步。
- **环境音**：海浪、风过林梢、室内房间音、雪原风等环境底噪，可以关掉。
- **主音量**。

用「素材库」发声需要先生成语义索引（见「语义检索」），因为素材是按检索语句从库里挑的。

### 修改区域

点舞台左上角的笔形按钮进入编辑。眼睛按钮可以显示或隐藏区域轮廓。

- 改形状：拖动顶点，点边线加顶点。删除顶点：双击它，或点一下选中（变成实心蓝点）后按 Delete。每块区域至少保留 3 个顶点。
- 「新区域」画一块新区域；「撤销」或 Ctrl+Z 撤销；「完成」或 Esc 结束编辑。
- 编辑时左栏变成「编辑区域」：在舞台上点一块区域，就能设置它怎么响；点区域之外是「底面」。区域被别的区域盖住时可以「置顶」，也可以「删除」。

每块区域的声音有两种设置方式：

- **写实材质**：木、金属、玻璃、石/混凝土、塑料、纸箱、泥土、碎石、雪、落叶、沙、草地、棉布、水。
- **新建自定义声音**：给一个名字，选「物理底子」（实体手感，也可以选「无实体」），再加最多 2 个「风格层」，例如能量/力场、电弧、激光、全息/界面、机械/伺服、黏液、魔法、卡通。每个风格层有「比重」，越大越盖过物理底子。「音高」可以在低沉、标准、尖细之间调。

用素材库发声时，每种动作有一条「检索语句」。默认按材质和风格组合自动生成；用过 AI 识图的，会用 AI 写的语句。你可以改写它，也可以选「不组池（直接合成）」。

### 管理素材池

右栏列出每块区域的素材池：CoAudio 从库里挑出的录音，演奏时在池里轮换取声。

- 点文件试听原文件。在舞台上一开始演奏，试听就会自动停止，两边的声音不会叠在一起。
- 「只用这个」：这块区域之后只用这一个文件发声，再点一次取消锁定。
- 「剔除」：从池里移除，之后重新组池也不会再选它。
- 「更多候选」：看还没进池的候选，试听后可以「加入素材池」。

组池时、或库里没找到合适素材时，会先用合成音色顶上，并在池上标出原因。

### 录制和导出

1. 点顶栏的「录制」（或按 R）开始，再点一次停止。
2. 点「导出」，把刚录的那一段渲染成 24-bit WAV，写进音频库并重新入库。

顶栏的电平表显示输出音量，鼠标停在上面能看到同时发声的声部数。导出目录和合成台共用同一个设置。

### 给视频配拟音

左栏点「载入视频」，或把视频文件直接拖到舞台上。目前支持 3 分钟以内的片段（mp4、mov、mkv、webm、avi）；浏览器播不了的编码（如 HEVC、ProRes）会先自动转一份可播放的副本，几秒到几十秒。

载入后舞台上放视频，下方是时间线：胶片条，以及「脚步」「碰撞」「接触」三条轨。整块舞台默认是一种材质（左栏选）；停在想要的画面上点「颜色识别」或「AI 识图」，可以按当前这一帧分出各处怎么响。

**对着画面演**

1. 把播放头放到要开始的地方，点顶栏「录到画面」（或按 R）。视频从这里开始播放。
2. 跟着画面演：在舞台上点、拖（和平时演奏一样），或者按 F、J 踩左右脚。
3. 再点一次（或按 R）停止。刚才的每一下按「按下那一刻屏幕上的画面」放到时间线上。

可以分几遍录：先踩脚步，再补碰撞，再录摩擦。录的时候，已经录好的声音会一起播放。「0.5×」半速播放更容易踩准（拟音轨会跟着变慢变低）。

**在时间线上修改**

- 点刻度或胶片条跳到那里，按住拖动可以来回拖播放头。
- 点一个音效点选中并试听；Shift 或 Ctrl 加选；在空白处拖出方框多选。
- 拖动选中的点调整时间；选中脚步或碰撞后，可以在时间线上方调「力度」。
- Delete 删除，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Ctrl+A 全选。
- Ctrl+滚轮放大，滚轮左右移动，「整段」缩回全部。

每一下都记住了录的时候用的素材和随机细节：挪动、删除别的点，或者之后换场景、改配方，已经录下的点声音不变。

**播放与快捷键**

空格播放/暂停，← → 逐帧（按住 Shift 一次一秒），Home 回到开头。「原声」可以打开原视频的声音做参考。

**导出**

- 「拟音轨（WAV，入库）」：与视频等长、从第 0 秒开始的 24-bit WAV，放进 DAW 和视频对齐即可。
- 「带声视频」：画面不重新编码，换上拟音轨（「原声」开着时会把原声压在下面混进去），写在原视频旁边，文件名是「原名_拟音」。

同一个视频再次载入时，上次的音效点会自动恢复。

## 18. 云端账号和团队协作

如果你只用本地库，可以跳过这一部分。

云端协作是 CoAudio 区别于普通本地音效库的关键能力。它不只是把文件上传到服务器，而是把素材、元数据、权限、编辑历史、审计记录和跨设备取流放在同一套协作模型里。

你可以用三个关系理解它：

- C-C：个人到个人。适合创作者之间共享个人库、多设备访问、个人分布式素材流转。
- B-B：组织到组织或团队到团队。适合工作室、项目组、外包团队、声音供应商之间按项目协作。
- B-C：组织到个人。适合组织把项目素材、安全授权素材或精选资产开放给个人创作者、自由职业者、客户审核人员。

### 登录或注册

1. 点顶栏右侧的头像，或打开「设置 → 用户 / 团队」。
2. 「服务器地址」：正式版默认已经填好 CoAudio 官方云服务。如果单位自建了服务器，填单位给的地址，例如 `https://cloud.example.com`。
3. 选「登录」「注册」或「忘记密码」。注册和重置密码需要邮箱验证码：点「发送验证码」后去邮箱查收（也看看垃圾箱）。
4. 开发服务器没配邮箱时，界面会直接显示验证码。

有的服务器会限制注册，比如只允许单位邮箱，或只允许受邀的人注册。被拒时会提示「该邮箱不能在此服务器自助注册」。这时请先让管理员邀请你（组织邀请或库共享都可以），再用被邀请的那个邮箱注册。

### 账户页

登录后，账户页顶部显示你的账号、在线状态和所连的服务器，「退出」回到纯本地模式。下面分几页：

- 概览：可访问的库数量、素材总数、本机节点状态，以及你的库列表。点一行库就在主界面浏览它，再点一次取消。
- 组织：你所在的组织；新建组织；管理员还能新建组织库、邀请成员。
- 库：可访问的库、新建个人库、接受邀请、上传到组织库、共享个人库。
- 共享网络：把本机加入共享网络，见「个人分布式库和节点」。
- 审计：你管理的库上的操作记录，只有管理员能看到这一页。

### 云端库类型

云端库分为：

- 个人库：适合个人分布式库和共享。
- 组织库：适合团队集中管理，通常上传源文件。

### 创建组织

1. 账户页 →「组织」。
2. 输入组织名称，点「新建组织」。
3. 创建者自动成为这个组织的管理员，并自动得到一个「组织名 组织库」。

有的服务器只允许指定账号创建组织，这时会提示「此服务器只允许指定账号创建组织」，请联系服务器管理员。

### 邀请成员

1. 在「组织」页的「邀请成员」里选组织，填对方邮箱，选角色。
2. 点「生成邀请」，把出现的邀请码复制发给对方。
3. 对方在「库」页的「接受邀请」里粘贴邀请码，点「加入」。

角色大致含义：

- 管理员：管理组织、库和成员。
- 可编辑：上传和编辑素材。
- 只读：查看、检索、试听，下载能力按服务端权限控制。

### 创建组织库

在「组织」页的「新建组织库」里填库名、选所属组织，点「创建」。只有组织管理员能建。

组织库适合团队共享素材。上传后，有权限的成员可以从自己的电脑检索、试听和拖拽。

### 上传到云端

有两种常见方式：

**上传到组织库**  
用于 B 端组织库，源文件会上传到云端存储。在账户页「库」→「上传到组织库」里选目标库，再「选文件」或「选文件夹」（文件夹会保留层级）。也可以在主界面选中一个云端组织库后，用列表上方的「上传文件」「上传文件夹」。需要可编辑或管理员权限。

**同步到个人云库**  
用于个人分布式库，只同步元数据和本机持有关系，音频留在本机。点侧栏「音频包」旁的云朵按钮整库同步，或在侧栏右键某些包、某个分组单独同步。

使用时要注意当前选择的是个人库还是组织库。

## 19. 三种云协作场景：C-C、B-B、B-C

### C-C：个人到个人

C-C 是最轻量的协作关系。它适合两个或多个个人创作者之间共享声音素材。

典型场景：

- 你在工作站上有一套个人 Foley 库，想让笔记本也能检索和试听。
- 你和另一位声音设计师一起做短片，希望互相开放精选素材。
- 你临时把某个个人库共享给协作者，让对方只在项目周期内使用。
- 你希望字节尽量留在本机，但云端能同步元数据和持有关系。

推荐流程：

1. 登录云端。
2. 创建或使用自己的个人库。
3. 在侧栏选择“同步到个人云库”。
4. 将本地素材的元数据、向量和持有关系登记到云端。
5. 在个人库中生成授权码或共享邀请。
6. 对方登录后接受共享。
7. 对方即可在权限允许范围内检索、试听或取流。

注意：个人分布式库依赖持有节点在线。如果源文件所在电脑离线，对方可能能看到元数据，但无法取到真实音频字节。

### B-B：组织到组织、团队到团队

B-B 是更正式的项目协作关系。它适合有组织边界、角色权限和交付责任的团队工作。

典型场景：

- 游戏公司和外包声音团队共享某个项目库。
- 声音工作室给剪辑、动效、混音团队提供统一素材入口。
- 多个内部项目组各自维护组织库，但希望资产结构统一。
- 供应商交付素材后，甲方需要审计下载、编辑和上传记录。

推荐流程：

1. 创建组织。
2. 创建组织库。
3. 邀请成员加入组织。
4. 给成员分配角色：admin、editor、viewer。
5. editor 上传素材到组织库。
6. 成员按权限检索、试听、下载和编辑。
7. 管理员查看编辑历史和审计记录。

B-B 的重点是“库即边界”。每个组织库都可以代表一个项目、一个部门、一个客户或一个交付阶段。团队不再依赖网盘链接和口头规则，而是通过角色、历史和审计来管理声音资产。

### B-C：组织到个人

B-C 是组织资产进入个人工作台的关系。很多真实项目都需要个人参与：自由声音设计师、远程剪辑师、临时外包、导演、客户审核人员等。

典型场景：

- 工作室把项目音效库授权给自由声音设计师。
- 组织给个人成员开放精选素材库。
- 客户只需要试听或下载某批声音，不应该获得编辑权限。
- 企业素材库希望被个人创作者在桌面端像本地库一样使用。

推荐流程：

1. 组织管理员创建组织库。
2. 上传或整理需要开放的素材。
3. 邀请个人用户加入组织，按需要给「只读」或「可编辑」角色。组织库只能通过组织成员身份开放；「共享个人库」只用于个人库。
4. 根据角色控制能力：viewer 试听/查看，editor 可上传/编辑，admin 可管理。
5. 个人用户在桌面端选择该云库。
6. 像使用本地库一样搜索、试听、拖拽，但操作仍受组织权限约束。

B-C 的价值是两边都舒服：个人不需要学习复杂后台，仍然在 CoAudio 桌面端工作；组织不用把整包素材裸发出去，仍然保留权限和审计。

## 20. 个人分布式库和节点

个人分布式库的目标是：素材不一定全部上传到中心，但云端知道谁持有这份素材，以及如何在授权情况下取流。

### 加入共享网络

1. 打开账户页 →「共享网络」。
2. 点「加入共享网络」。
3. 本机会向云端注册为一个节点，并建立取流隧道（不需要公网 IP 或端口转发）。
4. 同步个人库后，本机会登记自己持有哪些云端资产。

页面会显示节点状态。节点凭证失效时，点「重新注册节点」即可恢复。

当持有节点在线时，授权用户可以通过云端定位并取流。

### 什么时候会取不到

可能原因：

- 持有素材的电脑离线
- 节点未注册
- 节点心跳停止
- 网络隧道未连接
- 本机文件被移动或删除
- 权限不足

## 21. 审计和历史

云端协作场景下，CoAudio 记录关键操作：

- 上传
- 下载
- 编辑
- 授权
- 接受邀请
- 撤销授权
- 注册
- 重置密码

素材字段编辑会记录版本历史。团队可以知道某个描述、关键词或分类是谁改的。

## 22. 管理后台

平台管理后台给服务器运维用，独立于普通用户账号。需要服务端配置 `CO_ADMIN_TOKEN`。

启用后在浏览器打开服务器地址加 `/admin`，例如：

```text
https://cloud.example.com/admin
```

输入管理员令牌后点「连接」。后台可以查看：

- 概览
- 用户
- 组织
- 库
- 节点
- 授权
- 审计

也可以做这几件事：

- **停用 / 恢复账号**（用户页）：停用后对方立即被登出，不能再登录或重置密码，也看不到任何库。数据和成员关系都保留，恢复后照常使用。适合员工离职、账号被盗等情况。
- **转移组织所有者**（组织页）：把组织交给另一个已注册账号，对方成为该组织的管理员。适合组织管理员离职、组织没人能管的情况。原所有者的身份不变，需要的话再停用他的账号。
- **删除组织**（组织页）：连同所有组织库和库里的素材一起永久删除，要输入组织名确认，不能恢复。成员账号本身不受影响。

每个操作都会记一条审计，操作者显示为平台管理员。管理员令牌等于整台服务器的最高权限，只交给运维负责人。

## 23. 企业自建中心服务器

默认情况下大家都连 CoAudio 官方云。企业也可以把一整套云端服务部署在自己的服务器上，账号、组织和素材都留在企业内部，和官方云完全独立。

**部署**：由企业 IT 按仓库里的 `docs/DEPLOY.md` 用 Docker 部署（应用、Postgres、Qdrant、HTTPS 代理），需要一台 Linux 主机和一个指向它的域名。

**收紧准入**：服务器放在公网时，建议在 `cloud/.env` 里设置：

```bash
CO_SIGNUP_ALLOW=corp.com            # 只有这个域名的邮箱能自助注册
CO_ORG_CREATORS=it-admin@corp.com   # 只有这个账号能创建组织
```

- 可以写多个邮箱或域名，用逗号隔开；留空表示不限制，`none` 表示谁都不放行。
- 被组织邀请或被库共享的邮箱不受注册限制，所以外部协作者照常邀请就行。
- `CO_SIGNUP_ALLOW=none` 就是纯邀请制。

**员工怎么用**：在登录界面把「服务器地址」改成企业地址，然后注册、登录。一个客户端同一时间只连一个服务器，要切换就先「退出」再换地址登录。

**谁来管**：企业服务器的账号和组织由企业自己的管理员在 `/admin` 后台管理，CoAudio 官方看不到也管不了。客户端仍然从官方渠道自动更新，服务器的升级则由企业自己执行。

## 24. 设置页常用项

设置页左侧分为：用户 / 团队、音频库、大模型、快捷键、工具状态、关于。

### 音频库

- **已索引文件夹**：添加文件夹，或对已有文件夹重新定位（文件夹搬家后用）、重新扫描、移除。
- **元数据入库**：当前是否在扫描、进度和错误。
- **AI 语义检索（CLAP）**：已嵌入数量、当前用 CPU 还是 GPU，「生成 / 继续嵌入」「重建语义索引」。检测到 NVIDIA 显卡时会出现「启用 GPU 加速」，下载约 2.5GB 的 GPU 运行包后嵌入会快很多；出问题可以「回退 CPU」。

### 大模型

配置协议、Base URL、API Key 和模型名，见「AI 设置」。

### 快捷键

设置唤出 / 收起窗口的全局快捷键，默认 `Ctrl+Alt+S`。点「录制」后按下新的组合即可，组合里必须带 Ctrl、Alt 或 Shift 之一。和别的软件冲突时会提示。

### 工具状态

检查 ffmpeg、ffprobe、bwfmetaedit 等工具是否可用。

这些工具影响：

- 波形生成
- 时长探测
- 转码
- 元数据写回
- 裁剪导出

### 关于

查看当前版本（以及是 CPU 标准版还是 GPU 版），检查更新，下载完成后「重启并更新」。便携版会提示打开下载页。

## 25. 推荐的新手练习

### 练习 1：建一个本地库

1. 添加一个小音效文件夹。
2. 等待扫描完成。
3. 搜索 `hit` 或 `rain`。
4. 试听 5 条素材。
5. 收藏 2 条素材。

目标：熟悉扫描、搜索、试听和收藏。

### 练习 2：整理一个包

1. 在侧栏找到一个音频包。
2. 给它加入虚拟分组。
3. 选中几条素材。
4. 批量写入项目名或关键词。

目标：理解音频包和虚拟分组。

### 练习 3：启用语义检索

1. 生成 CLAP 嵌入。
2. 输入一句自然语言。
3. 找到一条接近的声音。
4. 使用查找相似。

目标：理解语义检索和以音搜音。

### 练习 4：用合成台做一个新声音

1. 打开合成台。
2. 输入一句 brief。
3. 试听候选。
4. 加入 3 条声音到时间线。
5. 调整淡入淡出和音量。
6. 导出 WAV。
7. 在主库中搜索导出的新声音。

目标：完成从检索到创作再入库。

### 练习 5：用拟音台录一段脚步

1. 打开拟音台，选预置场景「林间小径」。
2. 音源选「纯合成」，顶栏动作选「脚步」。
3. 在舞台上按住拖动走一圈，感受快走和跑步的区别、跨过不同地面时声音的变化。
4. 点「录制」，走一段，再点一次停止。
5. 点「导出」，然后在主界面搜索导出的「拟音_」文件。
6. 有语义索引的话，把音源换成「素材库」再走一遍，看右栏素材池里用到了哪些录音。

目标：理解材质区域、动作和两种音源。

### 练习 6：跑通云端协作

1. 启动云端开发服务。
2. 注册 Alice 和 Bob。
3. Alice 创建组织。
4. Alice 邀请 Bob。
5. Alice 上传素材到组织库。
6. Bob 登录后试听和检索。

目标：理解组织、角色和云端库。

### 练习 7：理解 C-C、B-B、B-C

1. C-C：创建个人库，把一个包同步到个人云库，再共享给另一个账号。
2. B-B：创建组织库，邀请另一个账号作为 editor，上传素材并查看编辑历史。
3. B-C：把同一个组织库授权给 viewer，让对方只负责检索、试听和下载。

目标：理解云协作不是单一上传，而是围绕“谁拥有、谁可用、谁可改、谁负责”建立资产关系。

## 26. 常见问题

### 为什么我的素材搜不到？

可能原因：

- 文件夹还没扫描完成
- 当前选择的是云端库而不是本地库
- 当前筛选了某个音频包
- 当前在收藏夹或最近使用视图
- 关键词不在已有元数据中
- 语义索引还没生成

建议先切回“全部资源”，清空筛选，再搜文件名的一部分。

### 为什么语义检索不可用？

可能原因：

- CLAP 依赖没安装
- 还没生成嵌入
- 模型加载失败
- 当前设备内存或 GPU 不足
- 索引任务正在运行或被暂停

先在设置页查看语义索引状态。

### 为什么波形不显示？

可能原因：

- ffmpeg/ffprobe 不可用
- 文件格式无法解码
- 文件已移动或删除
- 云端 mesh 资产持有节点离线

### 为什么拖到 DAW 失败？

本地素材：

- 检查源文件是否还在原路径。
- 检查 DAW 是否接受该格式。

云端素材：

- 检查是否有下载权限。
- 检查网络。
- 检查 token 是否过期。
- 检查云端文件是否存在。

### 为什么云端素材能看到但不能播放？

可能原因：

- 没有试听权限
- central 文件缺失
- mesh 持有节点离线
- 节点隧道未连接
- 云端服务地址配置错误

### 为什么合成台导出被取消了？

有片段的素材没加载成功，比如云端持有节点离线、文件被移动。为了保证导出的成品完整，这时导出会被取消，并列出是哪几条。处理好来源后重新导出，或删掉那几个片段。

### 拟音台为什么一直是合成音色，素材池是空的？

用「素材库」发声需要语义索引。先在「设置 → 音频库」里生成 CLAP 嵌入；第一次加载模型较慢，期间会先用合成音色顶上。如果池上提示「库里没找到合适的素材」，可以在「编辑区域」里改写这块区域的检索语句。

### 拟音台 AI 识图失败？

- 先确认「设置 → 大模型」已配置，并且所选模型能看图。
- 识图结果不理想时，可以进「编辑区域」手动改区域形状和声音。

### 点 × 关不掉 CoAudio？

点 × 只是收进托盘，程序还在后台运行。要彻底退出，右键系统托盘里的 CoAudio 图标，选「退出 CoAudio」。如果窗口真的卡住没反应，用任务管理器结束 CoAudio。

### 注册时提示「该邮箱不能在此服务器自助注册」？

这台服务器限制了注册，只允许特定邮箱或受邀的人。请联系服务器管理员邀请你，再用被邀请的邮箱注册。

### 登录时提示「账号已停用」？

服务器管理员停用了你的账号。你的数据都还在，请联系管理员恢复。

### 新建组织时提示「此服务器只允许指定账号创建组织」？

这台服务器只允许指定的人创建组织。请让有权限的人建好组织后邀请你加入。

## 27. 给团队的推荐流程

### 小团队

1. 每个人先建立本地库。
2. 统一 UCS 和关键词习惯。
3. 配置 CLAP 语义索引。
4. 建一个组织云库放项目共享素材。
5. editor 负责上传和编辑，viewer 负责查找和下载。
6. 每周整理一次元数据和分组。

### 大团队

1. 自建中心服务器（见「企业自建中心服务器」）：Postgres、Qdrant Server、对象存储，多副本部署时加 Redis；放在公网时设置准入名单。
2. 按项目或部门建立组织库。
3. 配置角色权限。
4. 规定上传命名、UCS、关键词和审计规范。
5. 使用管理后台观察用户、库、节点和审计状态；有人离职时停用其账号，必要时转移组织所有者。
6. 将本地个人库和组织库分开治理。

## 28. 最佳实践

- 不要一开始就导入所有历史素材。先用一两个高质量文件夹试跑。
- 先保证普通搜索、试听、拖拽都正常，再生成语义索引。
- 元数据字段宁可少而准，不要一次性乱填很多。
- 用虚拟分组整理包，不要轻易移动源文件。
- 重要文件写回元数据前，确认备份策略。
- 云端组织库适合共享源文件；个人分布式库适合个人设备间同步和持有登记。
- 合成台、拟音台导出的成品建议重新补描述、关键词和 UCS 分类。
- 团队协作时明确谁是 admin、谁能 editor、谁只能 viewer。
- 做云端协作前，先判断关系类型：个人之间用 C-C，团队/组织项目用 B-B，组织开放给个人创作者用 B-C。

## 29. 一条完整的从零到产出路线

1. 启动 CoAudio。
2. 添加本地音效文件夹。
3. 等待扫描完成。
4. 在搜索框输入一个明确关键词。
5. 试听素材并收藏几条。
6. 打开设置，生成语义索引。
7. 输入一句自然语言找声音。
8. 使用查找相似扩展候选。
9. 编辑命中素材的描述和关键词。
10. 将素材拖入 DAW，确认工作流打通。
11. 打开合成台，用一句 brief 拆层。
12. 加入多条素材到时间线，调整音量和淡入淡出。
13. 导出新声音并重新入库。
14. 需要跟画面的拟音时，用拟音台载入画面，录一段脚步或碰撞并导出。
15. 如果有团队需求，登录云端。
16. 创建组织库，上传项目素材。
17. 邀请成员，分配角色。
18. 用审计和历史跟踪协作修改。

完成这条路线后，你就已经掌握了 CoAudio 的核心价值：从混乱素材到可检索资产，从单条声音到组合设计和画面拟音，从个人硬盘到团队共享。
